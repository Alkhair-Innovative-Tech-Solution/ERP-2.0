# LMS Admin Dashboard

Modern admin dashboard for Learning Management System built with Next.js, React, and Tailwind CSS.

## Features

- 🎨 Modern, responsive UI design
- 👥 User Management
- 📚 Course Management
- 🔔 Notification Management
- 🏆 Certification Management
- 📊 Dashboard with statistics
- 🔐 Secure authentication

## Setup

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000)

## Default Login

- Username: `admin`
- Password: `admin123`

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Axios
- Lucide React (Icons)
