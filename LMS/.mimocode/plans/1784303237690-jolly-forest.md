# Phase 5 — Modern LMS UI Design Specification

## Design Philosophy

> "Use the SMS UI only as inspiration for layout and user experience. Design a modern interface for the LMS. Keep existing LMS branding, colors, and theme. Preserve the current design language."

### Approach
- **Keep** the LMS teal-based color palette (`#2a9f90`, `#264653`, `#c96928`)
- **Keep** the shadcn/ui component library
- **Keep** the Tailwind CSS utility-first approach
- **Keep** the App Router structure
- **Borrow** layout patterns, UX flows, and interaction patterns from SMS
- **Modernize** with glassmorphism, animations, and premium aesthetics

---

### Typography (Keep + Enhance)

### Sidebar Design (Enhanced from SMS)
- **Dark gradient background**: `linear-gradient(180deg, #020617, #0f172a)`
- **Teal accent**: Active item highlight with `#2a9f90`
- **Category grouping**: Collapsible sections with icons
- **Badge support**: Pending counts (e.g., "3" on Result Management)
- **User card at bottom**: Avatar, name, role, sign out
- **Smooth collapse**: 500ms transition, text fades, icons remain
- **Mobile overlay**: Full-screen backdrop on mobile/tablet

### Header Design (Enhanced from LMS)
- **Sticky**: `position: sticky; top: 0; z-index: 30`
- **Glassmorphism**: `backdrop-blur-md bg-slate-50/90`
- **Height**: 100px (spacious)
- **Left**: Page title (bold, tracking-tight)
- **Center**: Organization/Campus selector dropdown
- **Right**: Notification bell (with badge) → User avatar → Sign out button

## 3. Component Specifications

### 3.1 KPI Cards (from SMS, modernized)

**Pattern**: Grid of metric cards with circular progress indicators

```
┌─────────────────────┐ ┌─────────────────────┐ ┌─────────────────────┐ ┌─────────────────────┐
│  📊                  │ │  👥                  │ │  📈                  │ │  ✅                  │
│  ┌─────┐            │ │  ┌─────┐            │ │  ┌─────┐            │ │  ┌─────┐            │
│  │ 68% │  ↑ 12%     │ │  │2,450│  ↑ 5%     │ │  │ 1:30 │  ──       │ │  │ 94% │  ↑ 2%     │
│  └─────┘            │ │  └─────┘            │ │  └─────┘            │ │  └─────┘            │
│  Total Students     │ │  Active Enrolled    │ │  Teacher:Student    │ │  Avg Attendance     │
```

**Specs**:
- Background: White with subtle border
- Border radius: 24px (premium feel)
- Shadow: `--shadow-card` → `--shadow-premium` on hover
- Icon: Circular background with brand color
- Trend indicator: Arrow up/down with color (green/red)
- Progress ring: SVG circular progress

## 4. Page Specifications

### 4.1 Admin Dashboard

**Layout**: KPI cards (4 columns) → Charts (2x2 grid) → Recent activity

**Components**:
- Welcome banner with user name and time
- Branch/campus filter dropdown
- 4 KPI cards: Total Students, Active Enrolled, Teacher:Student Ratio, Avg Attendance
- 6 Charts: Enrollment Trend, Course Popularity, Attendance Trend, Gender Distribution, Fee Collection, Certificate Stats
- Recent Activity feed
- Quick Actions panel

### 4.2 Course Management

**List View**:
- Grid/List toggle
- Course cards with image, name, status, enrollment count
- Filter by specialization, status, branch
- Search by name

**Detail View**:
- Course header with image, title, description
- Tabs: Overview, Content, Enrollments, Assignments, Attendance, Grades
- Edit/Delete actions

**Create/Edit**:
- Multi-step form: Basic Info → Schedule → Fees → Review

### 4.3 Student Management

**List View**:
- Data table with avatar, name, ID, course, status, enrollment date
- Bulk selection with actions (export, delete, transfer)
- Advanced filters (branch, course, status, date range)

**Detail View**:
- Profile header with photo, name, ID, status
- Tabs: Profile, Courses, Attendance, Fees, Certificates, Activity
- Edit profile action

### 4.4 Attendance

**Marking View**:
- Class selector dropdown
- Date picker
- Student list with Present/Absent/Late/Leave buttons
- Bulk mark (All Present, All Absent)
- Save/Submit buttons

**Report View**:
- Date range selector
- Student/course filter
- Attendance table with status indicators
- Export to CSV

### 4.5 Fee Management

**Collection View**:
- Student lookup (ID or name)
- Outstanding fees list
- Payment form (amount, method, reference)
- Receipt generation

**Report View**:
- Fee collection summary cards
- Monthly/weekly trends chart
- Outstanding vs collected breakdown
- Export to CSV/PDF

### 4.6 Assignments

**Teacher View**:
- Create assignment form (title, description, due date, attachments)
- Submissions list with grading interface
- Rubric-based grading (from Phase 1)

**Student View**:
- Assignment list with due dates
- Submission form (file upload, text)
- Grade/feedback display

### 4.7 Notifications

**List View**:
- Notification cards with title, message, timestamp
- Read/unread status
- Mark as read button
- Filter by type (all, unread, announcements)

## 6. Interaction Patterns

### Hover Effects
- Cards: `translateY(-2px)` + shadow elevation
- Buttons: `scale-[0.98]` on active
- Table rows: `bg-slate-50` background
- Links: Color transition to brand-teal

### Loading States
- Skeleton shimmer for initial load
- Spinner for button actions
- Progress bar for uploads

### Transitions
- Sidebar: 500ms ease-in-out
- Page content: 300ms fade-in
- Modals: 200ms scale-in
- Tooltips: 150ms fade

### Feedback
- Success: Green toast (Sonner)
- Error: Red toast with details
- Warning: Orange toast
- Info: Blue toast

## Summary

The design specification preserves the LMS's existing teal-based branding while borrowing layout patterns and UX improvements from the SMS. Key enhancements:

1. **Premium card styling** with layered shadows and hover lift
2. **Glassmorphism header** with backdrop blur
3. **Dark gradient sidebar** with teal accents
4. **Circular progress indicators** for KPIs
5. **Smooth animations** for page transitions and micro-interactions
6. **Responsive design** with mobile overlay sidebar
7. **Print-ready** views for reports and certificates

The implementation should follow the existing LMS component patterns (shadcn/ui + Tailwind) while incorporating the SMS's proven UX patterns (multi-step forms, approval workflows, data tables, charts).
